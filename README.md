# 🌸 Bloom Match Mahjong — Nature Garden Puzzle

A relaxing, flower-themed Mahjong Solitaire browser game where you match nature tiles, complete levels, collect seeds, and grow your own garden.

## 🎮 About the Game

Bloom Match Mahjong combines classic tile-matching gameplay with a peaceful nature and garden theme. Instead of traditional Chinese characters, the game uses recognizable nature-themed emojis.

Your goal is to clear the board by matching identical, available tiles and earn rewards to decorate your garden.

## ✨ Features

- 🌼 Nature-themed tiles featuring flowers and other nature objects
- 🧩 Mahjong Solitaire-style tile matching
- 🎯 Multiple levels with increasing difficulty
- 💡 Hint feature to help find matching pairs
- 🌱 Seed rewards for matching tiles and completing levels
- 🌳 Garden decorations to unlock with collected seeds
- 🏆 Level-completion rewards
- 🌐 Playable in a modern web browser
- 💻 Built with HTML, CSS, and JavaScript

## 🕹️ How to Play

1. Open the game in a modern web browser.
2. Find two identical, available tiles.
3. Select both tiles to make a match.
4. Continue matching pairs until the board is cleared.
5. Use the Hint button if you need help.
6. Complete the level to earn rewards.
7. Collect seeds and spend them on garden decorations.
8. Progress through the available levels and grow your garden.

**Tip:** Choose available tiles carefully. Some tiles may be blocked by other tiles.

## 📁 Files Included

- `index.html` — Game structure and interface
- `style.css` — Game appearance, layout, and styling
- `script.js` — Game logic, matching, levels, hints, and garden rewards

## 💻 Requirements

- Windows, macOS, Linux, or another compatible device
- A modern browser such as Microsoft Edge, Google Chrome, or Mozilla Firefox

No additional software installation is required to play the game.

## 🚀 How to Run

1. Download and extract the game files.
2. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
3. Open `index.html` in your browser.
4. Start matching tiles and growing your garden!
